Gogo Shell — friendlyurl:precheck

AC1 surface. The shell command is the automation entry point — same engine, same report as the Server Administration page.

How to run

Connect to the Gogo shell on the running portal and execute:

$ telnet localhost 11311
g! friendlyurl:precheck
g! friendlyurl:precheck --json   # machine-readable

Notes for the dev team

  • Per the story's technical notes, the command lives in a module that can be deployed independently — the Gogo command is the OSGi entry point, and the same engine is invoked from the Server Administration → Resources section.
  • The exact command name (friendlyurl:precheck) is a strawman. The Jira ticket says "e.g." — open question for the dev team.
  • --json is shown as the toggle here, but the exact flag name is open. Consider -f json or --format json for symmetry with other shell commands.
  • Exit code: should the command exit non-zero when issues are found, so it can be wired into CI/CD pre-deploy gates? Worth confirming.
  • Template scan should use regex/string matching for /web/ with awareness of false positives (e.g., the word "web" in prose). Snippet view above shows ±2 lines of context to make the call easy.
